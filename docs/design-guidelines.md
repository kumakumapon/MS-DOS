# KDESK と KGUI32 のデスクトップ設計

- 基準は 8×16 ドットの文字セル。タイトルは上下に余白を取り、KDESK は 1 セル、KGUI32 は 24 ドットを使う。見出しやボタンの幅は Shift-JIS のバイト数で確認し、全角文字を途中で切らない。
- 共通パレットのアクセントは濃青 `#3366AA`、選択中の印は琥珀 `#FFBB66`。タスクバーではフォーカス中の項目に高さ 2 ドットの下線を付ける。値は `tools/desktop-style.h` に置く。
- 主操作は別のボタンとして表示する。副操作は短い動詞でまとめる。削除や終了など確認を要する操作には、結果が分かる説明と取消しの導線を設ける。
- アイコンは 16 ドットの格子を基準に文字と併記する。タップで押せる導線を用意し、右クリックに依存しない。ショートカットはボタンと重ならない案内欄に置く。
- 画面の上下をシステム操作とタスクバーに確保する。起動時の Welcome と System は、640×400 と 800×600 の作業領域に影ごと収める。KGUI32 の描画とクリック判定は同じランチャー矩形を使う。
- UI の定型ラベルは共通の `tools/kgui32/ui/strings.tsv` から Shift-JIS に変換する。起動時の設定ファイルは `KUMAUI.CFG` とし、先頭行が `JA` のとき日本語を選ぶ。

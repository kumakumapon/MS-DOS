# MS-DOS 4.0 の PC-98 / WebNP2 移植

MS-DOS 2.0 の移植を土台に、公開されている `v4.0` の DOS カーネルと
COMMAND.COM を PC-98 上で起動するための作業です。

## 完了条件

- 元の DOS 4.0 ソースと同梱ツールからカーネル・シェルをビルドする。
- PC-98 用 IPL、CON、CLOCK$、1024 バイトセクターの FD ドライバーを接続する。
- IBM PC 固有の SYSINIT 処理を PC-98 用に変更し、NEC BIOS の割り込みを保つ。
- WebNP2 上で `VER` が 4.00 を示し、ファイルの書込・読込・コピーと
  DOS アプリケーションの起動・終了を検証する。
- 起動ディスク、再現手順、制限、検証記録を公開する。

現段階では DOS 4.0 の PC-98 起動は未検証です。既存の
`ports/pc98` は引き続き DOS 2.0 の検証済み移植です。
初期対象は WebNP2 の 386 設定と 1.23 MB FAT12 FD です。
HDD、FAT16、漢字表示、IBM PC 専用の付属ドライバーは別途検証が必要です。

# 32bitアプリのタップ用メニュー

Calculator・Clock・Files・Editor・Images・User dictionaryは、タイトルバー左の
**Menu**を左クリック／1本指タップすると、ウインドウ内に操作一覧を表示します。
右クリック、長押し、ホバーやドラッグはメニュー操作に不要です。F1でも開けます。
項目は高さ36画素、行間4画素で、収まらない項目はPrevious／Nextでページ送りします。
上下／Tabで項目移動、Enterで実行、Esc／Backでもとの画面へ戻ります。
メニューを開いている間、下の文書・画像へ入力を通しません。別ウインドウへ移ると閉じます。

- Editor: 新規・開く・保存・別名保存、検索・置換、選択・コピー・切り取り・貼り付け、
  Undo／Redo、LF／CRLF、復旧、IME設定、終了。選択モードでは現在のカーソルを始点にし、
  終点をタップして範囲を選べます。もう一度選択モードを選ぶと解除します。
- Files: プレビュー、更新、Root／Work、対応アプリで開く、前後ページ、終了。
- Images: 読込・保存・Root／Work・復旧、反転・左右反転・Undo・原画像、描画モード、
  拡大・縮小・等倍・プレビュー、終了。ファイル名にフォーカスがある場合も選択操作を実行します。
- User dictionary: 登録・削除・明示保存・再読込、TMP／BAK確認・復旧、IME切替、終了。
- Calculator: メモリ加算／減算／呼出／消去。メモリ保持中はMを表示します。
  既存の固定小数点計算器を使い、Cは計算のみ、Memory clearはメモリを消します。
- Clock: 12／24時間、ストップウォッチ、開始／停止、リセット。時計画面のWatchからも切替。
  DOS時計に基づく1秒単位、最大99:59:59、午前0時をまたいで継続し、背景でも進みます。
  手動の時計変更・1日以上サンプルが途切れた時間の補正や、終了後の計測保持は対象外です。

保存確認・復旧確認やIMEの未確定入力を開いている間は、メニューに「先に操作を完了」と
Backだけを表示します。メニューは確認・競合検査・原本／TMP／BAK保持を迂回しません。
終了も各アプリの未保存確認を通します。強制Endは従来どおり別の管理操作です。

## SDK

`menu.h`の`KmItem`は文字列と既存イベントのコマンドを保持する私有CPL3データです。
`kg_menu(items,count)`を`kg_open`の前に呼び、最大24項目を登録します。
`kg_menu_enable`で通常操作が可能かを通知します。`kg_poll`はメニュー中の入力を消費し、
選択時だけ登録したイベントをアプリへ返します。`kg_present`はメニュー中、文書フレームを
操作一覧で置き換えます。ABI 1／3144バイトは変更しません。

SUBSCRIBEの追加bit128 (`KG_INPUT_MENU`)を設定した所有者だけにタイトルボタンを表示し、
既存の世代／token照合を通した`KG_KEY`の16384 (`KG_MENU_KEY`)で開きます。
旧EXEの購読・入力・タイトルドラッグは維持します。アプリ側はF1 (280)も処理します。
メニュー項目IDは24576〜24599、Back／Previous／Nextは24608〜24610です。
受信したキー／ポインタ／解放を選択前にアプリへ通さず、右ボタン・解放・別ページの項目IDで
コマンドを実行しません。最小344×168から最大784×416まで、日本語ラベルを含めて40描画命令の
検証を通し、非対応の表示領域や他所有者へ描画しません。

`make -C tools/kgui32 all test`で入力、ページ送り、非活性確認、描画境界、時計の午前0時・
停止・上限を検証します。webnp2 Actionsでは390px幅のタッチ対応ブラウザから実際のCanvasを
タップし、PEGC／Cirrusの実CPL3、保存確認と原本保持、背景進行、終了・メモリ回収を検査します。
ローカルpreviewは使用しません。
